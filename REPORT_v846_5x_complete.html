01Executive Summary — what actually is in this app

Top v8.4.6 = coin-economy Instagram automation. Users log in (WebView + captcha), the auto-robot foreground service runs like/comment/follow/save orders per account; orders are signed by a hardened native core and sent to a C2 that relays to Instagram's private API.

⚠ Previous report corrections (5× findings)

  • 0x923c0 is NOT "custom AES" — it's a general custom-B64 decoder (94 callers, clock()-salted, alphabet @0x16f27, fail → b . hang). Every obfuscated string in the binary flows through it.

08Anti-tamper state machine

Counter page 0x10eab0..0x10f3a0 (147 QWORDs)

Global state: flags, epochs, ptr-cache finals. GATE 0x37160 reads A, computes A·(A−1)+B (MBA-encoded); must be ∈ {9,10} else b .. Counters advanced only by legit code (0x36dfc init, 12 sites) — patching counters desyncs the gate.

Trigger arsenal

FLAGCHECK 0xe89fc1,956 polls — kill-flag check at block boundaries b . self-loops146 hang traps (deliberate freeze on detection) custom-B64 failb . @0x92748 — silent hang on decode error 0xeb2d0 clustersyslog + abort — crash-with-log hot slots0x10ee90×178 · 0x10efd0×110 · 0x10eef0×88
Implication for the agent: hooks must be log-only — no patched returns, no counter writes. Intercept at import level (access / __open_2 / syslog / abort) and at detection-fn entry/exit (read flags, never write). Frida's own presence is what R1/R3/R4-R8 catch — so the gadget must be injected, not runtime-scannable maps-wise (gum-js-loop thread + maps lines), and the agent must run with the scanner's token table in mind.

14.1 What 0x923c0 actually is — proven, not inferred

ABI + call pattern

0x923c0(x0 = len, x8 = out-string-struct)

Every site: add x8, sp, #off; mov w0, #LEN; bl 0x923c0. 88/94 sites give an immediate LEN (table in v846_token_sites.json).

Input is never read

The per-byte loop (0x924ec–0x926fc) computes each output byte from (i, clock(), MBA-constants) only. Two completely different 36-byte inputs → byte-identical outputs.

Output = base64 token

Alphabet A–Z a–z 0–9 (62 chars @ 0x16f27, standard b64, no +/). E.g. len=36, fixed clock → xvd1ctjlj0NBJebzlwHtCeefuLiD4jxSWeJj.

Clock-seeded ⇒ non-deterministic

6 different clock() values → 6 different tokens. Impossible for fixed strings; exactly right for nonces / device tokens / request salts.

Counter-gates are theater

Output identical for 8 different counter states (incl. all-zero) at 0x10f4a0 / 0x10f480 / 0x10f330 / 0x10ec28. Gates punish tampering (b . hang), they do not select plaintext.

Rodata blobs are DECOYS

Alphabet-looking strings staged before each call (e.g. =!!%&ozz<{<&! @0x17230) are overwritten by the generator — their content is irrelevant.
