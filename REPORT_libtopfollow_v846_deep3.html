§1What this library does

The native layer is a complete client-side automation engine for Instagram actions (follow / unfollow / comment / note / save / seen), wrapped in heavy obfuscation. It:

1 · Talks to Instagram's private API

Builds requests against https://i.instagram.com/api/v2/ using per-action path segments (friendships/create/, media/, comment/, create_note/v2/, seen/, /save/) assembled natively from an Order model — the Java layer never sees the raw URL template.

2 · Runs its own C2 channel

A second Retrofit client targets nivafollower.app (cert-pinned, 3 pins) with topfollow_check.php; a 3,648-byte config blob is bulk-decrypted at runtime (CRYPTO-B) before client construction.

3 · Signs & verifies payloads

AES-128 (FIPS-197, 4 emulated mode-wrappers), SHA-256 via Java MessageDigest, hash_key/hash_type JSON fields, and an APK SHA-256 integrity pin (120-byte triple-encoded blob at 0x14ce4).

4 · Defends itself relentlessly

1,956 compromise-flag polls, 146 infinite-loop traps, an MBA-encoded call-epoch counter that makes every function order-sensitive, Frida/Xposed/LSPosed/deleted-library scanners, and a 10× embedded b64+zlib payload installer inside the response handler.

§2String decoding — the 0x86684 machine

All obfuscated rodata strings are decoded by one function, 0x86684 (ABI x0=src, w1=len, x8=dst). Short inputs (≤20 B) decode through an MBA byte loop; long inputs (≥31 B) take a segmented path through a JNI iterator walker (0x101cbc) that pulls segments from a live Java object — undecodable without a JVM, trivial to capture at runtime (hook post-call x8).

§7Anti-tamper state machine (quantified)

Beyond the 146 self-loop traps and 1,956 flag polls, v846 runs a call-epoch counter: global counters cached on the pointer page 0x10e080–0x10ff00 (158 slots, initialized in JNI_OnLoad) are MBA-checked at the entry of virtually every helper. A hook that skips, reorders or re-enters any gated native desyncs the epoch → silent b . hang.

Verified by 0x7c08c / 0xbdb68 (5 traps each). Because it is data, build #9's cleanest bypass = rewrite the 120-byte blob to the re-signed APK's own hash (agent writes it at load, before first verify) — no verifier NOP needed.

Obfuscation layers summary

  • MBA-encoded comparisons everywhere (n(n−1) parity idiom).
  • Control-flow: per-decode guard loops, 1,956 flag polls, 146 b . traps.
  • Strings: 0x86684 runtime decode + 2–4× base64 nesting + plain JNI pool (unencoded).
  • Names: JNI methods registered as x0011f1a2-style hashes.
  • Counters: global call-epoch state machine (158-slot pointer cache).
